# 实质负利率观察站 · 1949—2026

一个手机优先、单文件可离线打开的中国实质利率数据网站。

- **主文件**：`index.html`（数据、样式、脚本全部内联，约 238 KB）
- **数据截至**：2026 年 10 月；2026 年年度值为 1—10 月 / 前三季度年内值
- **实时金价**：页面会尝试从 [Gold API](https://gold-api.com/) 获取国际现货价；失败时使用内置快照
- **官方数据自动更新**：`server.py` 每 24 小时检查一次国家统计局 / 中国人民银行最新发布，页面自动同步；页面不提供手动刷新按钮
- **手动修订**：页面内“录入 / 修订月度数据”保存到浏览器 `localStorage`，全站图表与表格即时重算

把 `index.html` 通过 AirDrop、微信文件或网盘发到手机，用 Safari / Chrome 打开即可。页面不依赖外部 CSS/JS。

### 同一 Wi-Fi 下用链接打开（推荐，带自动更新）
在本目录运行：

```bash
python3 server.py
```

macOS 也可以直接双击 `start.command`，它会启动同一个服务。

然后手机访问 `http://<电脑局域网IP>:8080/`。本机当前局域网 IP 可用 `ipconfig getifaddr en0` 查看。服务进程会每 24 小时自动检查官方数据；页面加载时也会从 `/api/latest` 同步。

如果只想离线阅读，也可以用 `python3 -m http.server 8080 --bind 0.0.0.0`，但此时不会自动更新。

## 页面内容

1. **公式区**：实质负利率定义、《通论》实际通胀率公式，以及可输入 CPI / 定存 / M2 / GDP 的即时计算器。
2. **本月快照**：实质利率、CPI、一年定存、70 城房价、M2、GDP、货币扩张口径。
3. **年度曲线（1949—2026）**：可在“通论口径 / CPI / 货币扩张”间切换，红色区间为实质负利率。
4. **年度数据表**：CPI、定存、实质利率、CPI 口径、货币口径、GDP、M2、房价、100 元购买力、黄金 ¥/g。
5. **月度曲线（2000-01—2026-10）**：近 5 年 / 2011 后 / 全部；含房价与 CPI 对照图、月度数据表。
6. **价格**：展示大米、猪肉、居民用电三种价格的年度变化，并附每年平均工资；不合成生活资料总量、不设权重、不计算购买力指数。
7. **金油比**：1949—2026 年黄金美元/盎司 ÷ WTI 原油美元/桶的年度趋势、长期均值与极值。
8. **数据与口径**：三种对照口径、数据源、月度录入器、CSV / JSON 导出。

## 计算口径

**主口径（《通论》，默认）**

```text
实际通胀率 = CPI 同比 + (M2 同比 − GDP 同比)

实质利率 = 一年期定存 − 实际通胀率
```

对应《通论》讲课稿 PDF p294、p338。该口径可以复现 2016—2020 连续 60 个月为负、2021 年短暂转正、2022 年后再次为负的结果。

**CPI 口径（对照）**

```text
实质利率 = 一年期定存 − CPI 同比
```

**货币扩张口径（对照）**

```text
实质利率 = 一年期定存 − (M2 同比 − GDP 同比)
```

这是研究性对照，不是《通论》的完整公式。

**房价**

房价是资产价格，不是《通论》公式里的通胀项。本站只把 70 城房价同比作为独立指标列示。此前本站自设过一个“CPI + 房价”加权口径，那没有《通论》依据，已移除。

## 重要数据边界

- **1949—1950**：CPI 缺失，年度表中的实质利率为空；1950 年一年定存 156% 未入图。
- **1951—1985**：CPI 为历史估算，不是现代口径的官方月度序列。
- **1987—2010**：房价为年度估算（依据商品住宅平均销售价格）；1987 为房价基年，没有同比，1988 年起使用房价同比。房价只作独立指标，不进入实质利率公式。通论口径 1987 年约 −13.7%，来自当年 M2 25.3% 与 GDP 11.7% 的差额。2011 年起为 70 城新建商品住宅同比中位数。
- **2000—2007**：月度 M2 使用年度增速估算；2008 年起为官方月度同比。
- **2026**：年度值为 1—10 月 / 前三季度年内值；月度最后更新为 2026-10。
- **价格**：大米、猪肉、居民用电为长期参考零售价，部分年份为整理/估算，不是官方月度发布；1950—1954 年价格已折算为第二套人民币。
- **价格口径**：大米、猪肉、居民用电为长期参考价，部分年份为整理/估算；1950—1954 年价格已折算为第二套人民币。
- **2026 年工资**：为估算值 135,000 元/年（按 2025 年官方 129,441 元约 +4.3% 外推），不是官方发布的 2026 年全年数据；2026 年全年工资通常要到 2027 年才发布。
- **金油比**：黄金为国际金价年均，原油为 WTI 年均；1949—1967 年黄金官价 35 美元/盎司，早期比值受管制价格影响。
- **黄金人民币折算**：1949—2001 年按国际金价与官方汇率折算，2002 年后国内金价逐步市场化；历史金币价不等于今天可成交的国内金价。
- 本页是数据工具，不构成投资建议。

## 自动更新机制

`server.py` 启动后会：

1. 在后台每 24 小时运行 `update_official.py`；
2. 抓取国家统计局 CPI、70 城房价、GDP 发布页，以及中国人民银行 M2 报告；
3. 把最新月份写入 `official_latest.json`，同时合并进 `data.js` 并重建 `index.html`；
4. 页面通过 `GET /api/latest` 同步；公开页面不提供手动刷新按钮，`POST /api/refresh` 也已关闭。

接口：

- `GET /api/latest`：最新官方快照
- `GET /api/status`：更新服务状态

注意：自动更新只覆盖 CPI、70 城房价、M2、GDP 等官方月度字段；一年期定存仍取主要银行挂牌（0.95%），金价走实时接口。生活资料价格、工资和金油比为年度参考序列，不由月度抓取自动改写。抓取失败时保留上一次快照，不会清空历史数据。

## 参考表核对

对 `5064066270497961.xlsx` 的 F 列做了反推，基本满足：

```text
实质利率 = 一年期存款利率 − (CPI指数/100 − 1) − (M2同比 − (GDP指数/100 − 1))
         = 一年期存款利率 − CPI同比 − (M2同比 − GDP同比)
```

- 数据区间：2016-01 至 2024-06，共 102 个月。
- 负值：92 个月；正值：10 个月（主要在 2021 年，以及 2024-06）。
- 最长连续负值：60 个月（2016-01 至 2020-12）。
- 最深：2020-03，约 −10.65%。
- 该列不是标准“定存 − CPI”，而是把 CPI 与 M2−GDP 同时扣掉，属于复合扣减，负值会更深。

站内“通论口径”即按此复算；统计区间从 2016 年起，避免把更早的高 M2 年份（如 1993 年）拉进来造成过度极端。

## 《通论》讲课稿依据

所提供 PDF 中的相关段落（页码为 PDF 页面序号）：

- **p294 / p338**：`实质利率 = 名义利率 − 实质通货膨胀`；`实质通货膨胀 = 名义通胀 +（M2增长率 − GDP增长率）`。这是站内“通论口径”的直接来源。
- **p295 / p386**：实质负利率不宜超过 −5%，最好控制在 −2% 以内；正 2% 到负 2% 相对合理。年度图上的绿色带即 −2%~+2%。
- **p80**：实质负利率到 10% 以上，会显著放大杠杆；p127 称 2008—2012 年中国出现过“超级实质负利率、恶性通胀”。
- **p274**：通胀包括房价、房租、电价、水费、煤气费、交通费等生活成本；这是站内保留电价等分项价格的依据；现在不再合成总量。
- **p113**：用黄金价值载量（35 美元/盎司 → 1840 美元/盎司）反思美元购买力，可作为“货币购买力折损”的旁证。
